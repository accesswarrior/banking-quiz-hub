# Banking Quiz Hub

A collection of interactive quiz apps for banking and finance courses.  
No server, no login, no data sent anywhere — everything runs in your browser.

## How to Use

1. Visit the Hub Page
2. Click any course to open its quiz
3. Choose mode, question count, and start!

All progress is saved locally in your browser.
